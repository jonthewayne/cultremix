# Launch metrics

Copy the numbers from `/admin/metrics` once a day. Days are UTC. The page recounts yesterday and today every hour; press **Recount these N days** if a day looks stale.

**Environment:** (staging / production)
**Launch day:** (date)
**Filled in by:** (name)

## What each number means

| Number | Counts |
| --- | --- |
| Members | Accounts created that day. |
| Members who generated | Members who pressed Generate for the first time that day. The total is everyone who ever has. |
| Batches | Generate presses (each asks for four designs). |
| Designs | Designs that came back (failed or blocked ones don't count). |
| Published works | Works created that day that are published, remixes included. |
| Remixes | Published works that aren't originals (they joined an existing family). |
| Families | New CR families started that day. |
| Credits used | Credits charged, minus credits given back for missing designs. Credits given by admins don't count. |
| Model photos | Photos of someone wearing a published design. |

## Ratios worth watching

Work these out from the totals.

| Ratio | How | Value |
| --- | --- | ---: |
| Members who made something | Generated ÷ Members | |
| Designs per batch | Designs ÷ Batches (4.0 means none went missing) | |
| Publish rate | Published ÷ Designs | |
| Remix share | Remixes ÷ Published | |
| Credits per member who generated | Credits used ÷ Generated | |
