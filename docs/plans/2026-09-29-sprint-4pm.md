### Studio `/studio` (one page for iterating)

- A drop zone for one inspiration image (drag it in, or click to choose; optional) and a text box: "What should change?" Optional style chips. Generate.
- **Background color:** sampled in the browser from the inspiration image's edges (the most common edge color), editable with a color picker, and stored with the batch. With no image, the default is off-white.
- Each Generate makes a batch of 4 tiles that fill in as they finish, newest batch on top. Tiles show the transparent design on the batch's background color.
- A heart on each tile. Clicking a tile opens the viewer: full size, ←/→ through favorites (or through the batch when there are none), Esc closes, a "3 / 11" position.
- "Use as inspiration" on a tile makes it the next inspiration image.
- "Publish" on a tile: an optional title, then the CR reveal, then it appears in the feed.

## How generation works

- **Designs:** `openai/gpt-image-2.5-sunburst` edit when there is an inspiration image (the image plus the instruction); `openai/gpt-image-2.5-flare` when there is only text. Transparent background, 1024×1536 (the print shape), shown centered in the squares. The prompt wraps the instruction: a t-shirt graphic, isolated, no shirt or mockup.
- **Model photo:** at publish, one Sunburst edit with the design as input: an editorial photo of a stylish young person wearing a t-shirt in the background color with this exact graphic printed on the chest, in one house photography style; opaque, 1024×1024. Stored as one `shoots` row with one `shootPhotos` row.
- AI SDK `generateImage` through the AI Gateway provider in Convex Node actions, `maxRetries: 0`, a timeout per call. A failed tile is marked failed and its credit refunded.
- The ops lane's image check (O2) confirms which calls return real transparency. The Builder uses whatever calls the check shows working.
